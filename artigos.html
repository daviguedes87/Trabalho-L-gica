Observação técnica: o site é estático (HTML, CSS e JavaScript) e fica hospedado no GitHub Pages, sem servidor próprio. Os artigos e comentários são gravados num banco de dados na nuvem (Supabase), acessado direto do navegador pela API REST. Por isso a turma inteira compartilha o mesmo conteúdo: o que você escreve aqui aparece para qualquer colega, em qualquer computador.
